## 🧪 Tips for Smooth Operation

### 📌 Keep It Running
Don't close the Nextcloud client. It runs in the system tray so you can forget about it. Closing it stops syncing until you reopen it.

### 💾 Check Sync Status
Right-click the cloud icon in the system tray. If you see a green checkmark, everything is synced. An orange arrow means files are uploading or downloading. A red circle means an error — click it for details.

### 📂 Selective Sync
If you have a very large cloud storage, you can choose which folders sync to your PC. Right-click the tray icon → **Settings** → **Account** → select the folders you want. This saves disk space.

### 🛡️ Security First
Keep your Windows updated and use a strong password for your Nextcloud account. Enable two-factor authentication on your server if possible — this client supports it seamlessly.
